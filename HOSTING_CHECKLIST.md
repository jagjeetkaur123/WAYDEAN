## 5. STEP-BY-STEP HOSTING GUIDE

### Option A: NETLIFY (Recommended - Easiest & Free)

1. Go to netlify.com
2. Click "Sign up" → Connect GitHub or use email
3. Create new site → "Deploy manually"
4. Drag & drop your folder (Index.html, Style.css, script.js)
5. Get free URL like: waydean-nursery.netlify.app
6. Go to "Site settings" → "Domain management"
7. Add your custom domain (waydeannursery.com.au)
8. Follow DNS setup instructions
9. SSL auto-enabled ✅

### Option B: Traditional Hosting

1. Register domain (godaddy.com or similar)
2. Buy hosting (Bluehost/SiteGround)
3. Upload files via FTP or File Manager
4. Point domain to hosting (via DNS records)
5. Enable SSL certificate
